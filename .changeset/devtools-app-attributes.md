The Traces view shows the attributes your code set first. Timeline rows show the first three after the span name, the hover card lists them all with full values, and the trace list tags each operation with its root span's attributes. The span panel lists them above a collapsed "Resource & auto" section that opens when the attribute filter matches inside it. Previews mask credential-shaped values with the same rule the span panel uses.
