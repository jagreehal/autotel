What the demo tools are hiding

search
Registered with four annotations. Chrome keeps readOnlyHint and untrustedContentHint and discards the rest without an error. Watch webmcp.annotations.dropped on its registration span.
clear_cart
Returns an empty string. Chrome substitutes Operation succeeded, so the agent reads a success message the handler never wrote.
describe_order
Returns an MCP { content: [...] } envelope. Chrome does not unwrap it, so the agent receives the JSON wrapper rather than the text inside.
checkout
Fails, then normalises the failure into a readable string the way a tool library does. The span still records error.type, because isErrorResult tells the instrumentation how to spot one.
