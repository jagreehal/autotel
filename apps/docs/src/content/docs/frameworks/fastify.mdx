## Setup

```typescript
// instrumentation.ts
import { init } from 'autotel';

init({
  service: 'my-fastify-api',
  autoInstrumentations: ['http'],
  endpoint: process.env.OTLP_ENDPOINT,
});
```

`@opentelemetry/auto-instrumentations-node` has no Fastify instrumentation, so there is no `'fastify'` name. For hook and handler spans, add Fastify's own [`@fastify/otel`](https://github.com/fastify/otel) through `instrumentations`:

```typescript
import FastifyOtelInstrumentation from '@fastify/otel';

init({
  service: 'my-fastify-api',
  autoInstrumentations: ['http'],
  instrumentations: [
    new FastifyOtelInstrumentation({ registerOnInitialization: true }),
  ],
});
```

Run with:

```bash
tsx --import ./instrumentation.ts src/index.ts
```

## Tracing Route Handlers

```typescript
import Fastify from 'fastify';
import { trace, withTracing, type TraceContext } from 'autotel';

const app = Fastify({ logger: true });

const fetchUser = withTracing({})(
  (ctx: TraceContext) => async (userId: string) => {
    ctx.setAttribute('db.userId', userId);
    await new Promise((resolve) => setTimeout(resolve, 50));
    return { id: userId, name: `User ${userId}` };
  },
);

app.get('/users/:userId', async (request, reply) => {
  const { userId } = request.params;
  try {
    return await fetchUser(userId);
  } catch {
    reply.code(500);
    return { error: 'Failed to fetch user' };
  }
});

app.get('/error', async () => {
  throw new Error('Test error');
});

await app.listen({ port: 3000 });
```

## What Gets Traced

With `autoInstrumentations: ['http']`:

- **HTTP server spans**: automatic per-request spans
- **Fastify lifecycle**: hook and handler execution time, with `@fastify/otel`
- **Your `trace()` calls**: business logic spans as children
